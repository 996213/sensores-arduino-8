03

Su bina coeducativa

Dos personas, una mesa, un circuito. Cada quien tiene un puesto y una responsabilidad distinta, y el producto es de los dos: si uno no entiende, la bina todavía no terminó.

Ingeniera de montaje

ella · manos en la protoboard
  • Ubica el LED, la resistencia y el pulsador, y respeta la polaridad.
  • Es la única que mueve cables: si algo hay que cambiar, se le pide a ella.
  • Lleva la bitácora de fallas: qué no funcionó y cómo lo resolvieron.
  • Le explica en voz alta a su compañero por dónde viaja la corriente.
entrega: montaje + bitácora

Programador

él · manos en el teclado
  • Escribe el código en el Arduino IDE, elige placa y puerto, compila y carga.
  • Lee los errores en voz alta: nadie depura un programa en silencio.
  • Hace las diez pruebas finales del botón y anota el resultado.
  • Le explica a su compañera qué línea hace que el LED cambie.
entrega: archivo .ino + tabla de pruebas
Pacto de la bina: nadie toca el material del otro rol sin avisar, y nadie se queda sin entender el circuito ni el código. Al llegar al reto de ampliación, intercambien las sillas: quien armó ahora programa.

Ruta de armado

Sigan el orden. Cada paso supone que el anterior ya quedó funcionando. La etiqueta de color indica a quién le toca.

1
los dos

Cuenten el kit y dejen el USB desconectado

Nunca se arma ni se cambia un cable con la placa energizada. Primero el circuito, después la corriente.

2
ingeniera de montaje

Ubica el LED y su resistencia

El LED va en la protoboard con la pata larga (ánodo) hacia el cable que viene del pin 8. La pata corta baja a la resistencia de 220 Ω y de ahí al riel azul (GND).

Ojo: un LED sin resistencia se quema. Y si queda al revés, simplemente no enciende.
3
ingeniera de montaje

Monta el pulsador sobre el canal central

Las cuatro patas deben quedar montadas a lado y lado del canal del centro. Una pata va al pin 2 y la pata diagonalmente opuesta va al riel azul (GND).

Truco: si el LED cambia sin que nadie toque el botón, probablemente el pulsador está girado 90°.
4
programador

Configura el Arduino IDE

Con el montaje ya revisado, conecta el USB. Entra a Herramientas → Placa: Arduino UNO y Herramientas → Puerto, y elige el que aparezca al conectar.

5
programador

Escribe el programa

Escríbelo, no lo copies y pegues. Escribirlo es lo que te permite encontrar el punto y coma que falta. Verifica con ✓ y carga con →, leyendo los errores en voz alta.

6
los dos

Prueben diez veces y expliquen

Oprimen el botón diez veces y cuentan los cambios. Si de diez pulsaciones el LED cambió nueve u once veces, hay rebote: revisen el delay(50). Cierren explicándose mutuamente su parte.

06

Lo que de verdad está pasando

Aquí está el concepto de la unidad. Cópienlo en el cuaderno con sus propias palabras: esto es lo que les voy a preguntar.

// El Arduino repite loop() miles de veces por segundo.
// Por eso no basta con preguntar "¿está oprimido?".

const int PIN_PULSADOR = 2;
const int PIN_LED      = 8;

bool ledEncendido   = false;  // ¿la luz está prendida?
int  estadoAnterior = HIGH;   // cómo estaba el botón la vuelta pasada

void setup() {                // se ejecuta UNA sola vez
  pinMode(PIN_PULSADOR, INPUT_PULLUP);
  pinMode(PIN_LED, OUTPUT);
}

void loop() {                 // se repite POR SIEMPRE
  int estadoActual = digitalRead(PIN_PULSADOR);

  if (estadoAnterior == HIGH && estadoActual == LOW) {  // ¡acaba de oprimirse!
    ledEncendido = !ledEncendido;      // invierte: true↔false
    digitalWrite(PIN_LED, ledEncendido);
    delay(50);                        // ignora el rebote del contacto
  }

  estadoAnterior = estadoActual;       // guarda para la próxima vuelta
}

setup() vs loop()

Toda la programación estructurada se arma con tres cosas: secuencia, decisión y repetición. setup() es la secuencia que corre una vez; loop() es el ciclo infinito.

variable de estado

ledEncendido es la memoria del programa. Sin ella, el Arduino no tendría forma de saber si la luz ya estaba prendida.

if con &&

La condición compuesta pregunta dos cosas a la vez. Solo se cumple en el instante exacto en que el botón pasa de suelto a oprimido: eso se llama detectar el flanco.

el operador !

!ledEncendido significa "lo contrario de". Una sola línea reemplaza dos condicionales: si estaba apagado lo prende, si estaba prendido lo apaga.

Pista de Bartolino: si el LED parpadea como loco mientras mantienen el dedo en el botón, no está dañado. Es que el programa está preguntando "¿está oprimido?" en lugar de "¿acaba de oprimirse?". Ahí está todo el concepto de hoy.

Para entregar

  • Circuito armado y funcionando: una pulsación enciende, la siguiente apaga.
  • Programa cargado desde el Arduino IDE, con comentarios escritos por la bina.
  • Cuaderno de cada integrante con los tres recuadros y mínimo tres fallas resueltas.
  • Sustentación de 3 minutos: la ingeniera explica el código y el programador explica el circuito.
  • Tabla actitudinal firmada por los dos y kit entregado completo.
